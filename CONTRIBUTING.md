# Contributing

We welcome contributions to `sherlock-rs`! To ensure a smooth process, please follow these guidelines:

## Code Hygiene

Before submitting your pull request, please ensure your code adheres to standard Rust hygiene practices:

-   **Clippy**: Run `cargo clippy --fix` to catch common mistakes and improve code.
-   **Formatting**: Run `cargo fmt` to ensure consistent code style.

## AI-Assisted Development

If you use AI coding agents (e.g., Claude Code, Codex, Amp, etc.) to assist in your contributions, please make a note where so the PR makes more sense when reviewing.

Thank you for contributing!
